# 6. 学習

[目次](README.md) ・ 前：[5. book](05-book.md) ・ 次：[7. 対局](07-play.md)

book の学習は、メインエンジンが book のコマンドを実行します。GUI は、エンジンに今の局面まで打たせてからコマンドを送り、終わるのを待ちます。学習の間も、探索用エンジンが評価値を出し続けます（book の精度の段階は学習の前の値を薄く出します）。

## 学習のコマンド

「学習」のメニュー。X・Y は右のパネルの「調べる範囲」の値です。

| 項目 | エンジンのコマンド |
|---|---|
| 今の局面から book deviate X Y（deviate2・deviate3 も） | `book deviate X Y` など |
| 今の局面から book enhance X Y | `book enhance X Y` |
| 今の局面から book leaf expand X Y | `book leaf expand X Y` |
| 今の局面から book fill 2 X Y（fill2 も） | `book fill 2 X Y`・`book fill2 2 X Y` |
| book play | どの手順も最善の手で深さまで伸ばす |
| 今の対局を book に追加 | `book store` |
| 棋譜ファイルを book に追加・手順リストのファイルを学習させる・book と比較 | `book add`・`book learn`・`book check` |
| 評価値を再計算する・リンクを修復する | `book negamax`・`book fix` |
| 完全読みの局面を確かめ直す | `book correct` |
| Leaf を再計算する（4 種） | `book leaf recalculate`〜`recalculate4` |

始める前に、コマンドと book のファイルを示す確かめの窓が出ます。学習中は、学習のコマンドを選べません。

## 中止・再開

- 「学習」→「学習を中止…」：book のコマンドは途中で止められないので、メインエンジンを終了して再起動します。窓には、いちばん新しい途中保存のファイル（`.dev`・`.dev2`・`.store` など、book の隣）と時刻が出ます。
- 「学習」→「途中保存から再開…」：book より新しい途中保存があれば、それを読み込み、最後の学習のコマンドを同じ局面から再開します。最後のコマンドは `config.ini` の `[learn] last_command` に残ります。

## 学習キュー

- 「学習」→「足りない進行をすべて学習キューに入れる」：book タブの足りない進行それぞれを、その局面まで打つ → `book store` → 精度の基準のコマンド（X Y）の 1 件にしてキューに入れます。
- 「学習キューを実行…」で順に実行します。中止すると、残りはキューに残ります。「学習キューを空にする」で空にします。
- スクリプトの `learn <コマンド>` でもキューに入れられます（[10. スクリプト](10-scripts.md)）。

## 学習の設定

「学習」→「学習の設定…」：メインエンジンに送る設定です（`config.ini` の `[learn_options]`）。

| 項目 | 意味 |
|---|---|
| 同時に広げる数・同時に入れる棋譜の数 | 数か auto（空はエンジンの設定のまま） |
| 時間ごとの保存（分）・周ごとの保存 | 途中保存の間隔（時間は 0 で時間では保存しない、周は 0 で終わったときだけ） |
| 乱数の種・毎回同じ book にする | 同じ book を作り直したいとき |
| Leaf の再計算の回数の上限 | 変化がなかった回で終わる |
| merge の後に .mrg へ・store の後に .store へ保存 | on か off |

## 注意

- book を変えるコマンドの後は、エンジンを閉じるときに book のファイルが保存されることがあります。大事な book はコピーを取ってから学習してください。
- 学習の速さとメモリはエンジンと book の大きさで決まります。大きな book の学習は時間がかかります。
