# 6. 学習

[目次](README.md) ・ 前：[5. book](05-book.md) ・ 次：[7. 対局](07-play.md)

book の学習では、メインエンジンが book のコマンドを実行します。

- GUI は、エンジンに今の局面まで打たせてからコマンドを送り、終わるのを待ちます。
- 学習の間も、探索用エンジンが評価値を表示し続けます。
- book の精度の段階は、学習の前の値を薄く表示します。

## 学習のコマンド

「学習」のメニューから選びます。X・Y は、右のパネルの「調べる範囲」の値です。

| 項目 | エンジンのコマンド |
|---|---|
| 今の局面から book deviate X Y（deviate2・deviate3 も） | `book deviate X Y` など |
| 今の局面から book enhance X Y | `book enhance X Y` |
| 今の局面から book leaf expand X Y | `book leaf expand X Y` |
| 今の局面から book fill 2 X Y（fill2 も） | `book fill 2 X Y`・`book fill2 2 X Y` |
| book play | どの手順も最善の手で深さまで伸ばす |
| 今の対局を book に追加 | `book store` |
| 棋譜ファイルを book に追加・手順リストのファイルを学習させる・book と比較 | `book add`・`book learn`・`book check` |
| 評価値を再計算する・リンクを修復する | `book negamax`・`book fix` |
| 完全読みの局面を確かめ直す | `book correct` |
| Leaf を再計算する（4 種） | `book leaf recalculate`〜`recalculate4` |

- 始める前に、確認のウィンドウが出ます。実行するコマンドと book のファイルが表示されます。
- 学習中は、学習のコマンドを選べません。

## 中止・再開

- 「学習」→「学習を中止…」：
  - book のコマンドは途中で止められないので、メインエンジンを終了して再起動します。
  - ウィンドウには、最新の途中保存のファイルと、その時刻が出ます。途中保存のファイルは book の隣にある `.dev`・`.dev2`・`.store` などです。
- 「学習」→「途中保存から再開…」：
  - book より新しい途中保存があれば、それを読み込みます。
  - 最後の学習のコマンドを、同じ局面から再開します。
  - 最後のコマンドは、`config.ini` の `[learn] last_command` に保存されています。

再開したときに、済んだ所をもう一度探索するかは、コマンドによって違います。次は、GUI 0.4.6 からの同梱のエンジンでの動きです。

- `deviate` 系・`enhance`・`leaf expand`・`fill`・`play`・`add`：済んだ所は探索し直しません。広げた手や足した局面が、book に残っているためです。
- `correct`・`leaf recalculate`：
  - 探索し直した局面は、book の中でマークされます。再開すると、マークのない局面だけを探索します。
  - 最後まで終わると、マークは外れます。
  - 途中保存のファイルは、`correct` が `.err`、`leaf recalculate` が `.leaf` などです。
- `learn`：
  - 学習した行の記録 `<book>.learn` を、book の隣に書きます。
  - 再開すると、棋譜のファイルのうち、学習済みの行を飛ばします。
  - 最後まで学習すると、この記録は消えます。

GUI 0.4.5 までの同梱のエンジンでは、次のとおりです。

- `correct`・`leaf recalculate`・`learn` は、再開すると最初からやり直していました。
- マークの付いた途中保存の book は読めません。壊れた book として扱われます。

## 学習キュー

- 「学習」→「足りない進行をすべて学習キューに入れる」：book タブの足りない進行を 1 本ずつ、1 件のジョブにしてキューに入れます。1 件の内容は次のとおりです。
  1. その局面まで打つ
  2. `book store`
  3. 精度の基準のコマンド（X Y）
- 「学習キューを実行…」で順に実行します。中止すると、残りはキューに残ります。
- 「学習キューを空にする」でキューを空にします。
- スクリプトの `learn <コマンド>` でもキューに入れられます（[10. スクリプト](10-scripts.md)）。

## 学習の設定

「学習」→「学習の設定…」：メインエンジンに送る設定です（`config.ini` の `[learn_options]`）。

- 学習の途中で変えた設定は、その学習が終わってから送ります。進んでいる学習は、前の設定のままです。
- メインエンジンが動いていないときは、次に起動したときに送ります。
- 欄を空にすると、エンジンの設定に戻すことになります。ただし、エンジンにはそれを送る方法がありません。そのため、動いているメインエンジンには、前に送った値が残ります。ログにもそう出ます。
- エンジンの設定に戻るのは、メインエンジンが次に起動したときからです。次のときに起動します。
  - 「エンジン」→「再起動」
  - book を開く・読み直す
  - GUI の起動

| 項目 | 意味 |
|---|---|
| 同時に広げる数・同時に入れる棋譜の数 | 数か auto（空はエンジンの設定のまま） |
| 時間ごとの保存（分）・周ごとの保存 | 途中保存の間隔（時間は 0 で時間では保存しない、周は 0 で終わったときだけ） |
| 乱数の種・毎回同じ book にする | 同じ book を作り直したいとき |
| Leaf の再計算の回数の上限 | 変化がなかった回で終わる |
| merge の後に .mrg へ・store の後に .store へ保存 | on か off |

## 注意

- book を変えるコマンドの後は、エンジンを閉じるときに book のファイルが保存されることがあります。大事な book は、コピーを取ってから学習してください。
- そのため、book を変えるコマンドの後にメインエンジンを閉じるときは、エンジンが book を保存して終了するのを待ちます。待つ時間に上限はありません。メインエンジンを閉じるのは、次のときです。
  - GUI を閉じる
  - book を開く・読み直す
  - エンジンを切り替える・再起動する
- エンジンは、book を隣の別のファイル（`<book の名前>.tmp.<番号>`）に書いてから、book と置き換えます。そのため、保存の途中でも、book のファイルは前のままです。
- 待つ間も、ウィンドウは使えます。
  - ログに「メインエンジンが book を保存して終了するのを待っています」と出ます。
  - 下の行には、「book を保存しています」と、経った時間が出ます。
  - 保存が終わったことも、ログに出ます。
  - 保存できなかったときは、その前にメインエンジンの ERROR の行が出ます。book のファイルは前のままです。
  - 続きの処理は、保存が終わってから行います。例えば、GUI を閉じる、新しい book でメインエンジンを起動する、などです。
  - 待つ間は、メインエンジンを使う操作はできません。学習、book の書き出し、book を開く・読み直す、エンジンの切り替え・再起動などです。保存が終わるまで待つように、メッセージが出ます。
  - スクリプトは、保存が終わってから次の行に進みます。
- 待つ間にもう一度閉じようとすると、保存を打ち切るかを尋ねます。
  - 「はい」：エンジンをすぐに終了させて閉じます。
    - book のファイルは、前に保存したときのままです。その後に学習した分は失われます。
    - 途中保存のファイルは残ります。
    - 書きかけの `.tmp.<番号>` のファイルが残ったときは、消してかまいません。
  - 「いいえ」：保存が終わるのを待ってから閉じます。
  - スクリプトの `quit` で閉じるときは、尋ねません。保存が終わってから閉じます。
- 学習中に閉じたときは、待たずにエンジンを終了させます。途中保存の後に学習した分は失われます。
- 学習の速さとメモリの量は、エンジンと book の大きさで決まります。大きな book の学習は時間がかかります。
