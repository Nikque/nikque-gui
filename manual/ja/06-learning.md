# 6. 学習

[目次](README.md) ・ 前：[5. book](05-book.md) ・ 次：[7. 対局](07-play.md)

book の学習は、主のエンジンが book の命令を行います。GUI は、エンジンに今の局面まで打たせてから命令を送り、終わるのを待ちます。学習の間も、探索だけのエンジンが評価値を出し続けます（book の精度の段階は学習の前の値を薄く出します）。

## 学習の命令

「学習」のメニュー。X・Y は右のパネルの「調べる範囲」の値です。

| 項目 | エンジンの命令 |
|---|---|
| 今の局面から book deviate X Y（deviate2・deviate3 も） | `book deviate X Y` など |
| 今の局面から book enhance X Y | `book enhance X Y` |
| 今の局面から book leaf expand X Y | `book leaf expand X Y` |
| 今の局面から book fill 2 X Y（fill2 も） | `book fill 2 X Y`・`book fill2 2 X Y` |
| book play | どの手順も最善の手で深さまで伸ばす |
| 今の対局を book に入れる | `book store` |
| 棋譜のファイルを入れる・手順のリストを打ち継いで入れる・book と比べる | `book add`・`book learn`・`book check` |
| 評価値を整える・link を張り直す | `book negamax`・`book fix` |
| 完全読みの局面を確かめ直す | `book correct` |
| Leaf を計算し直す（4 種） | `book leaf recalculate`〜`recalculate4` |

始める前に、命令と book のファイルを示す確かめの窓が出ます。学習中は、学習の命令を選べません。

## 止める・続ける

- 「学習」→「学習を止める…」：book の命令は途中で止められないので、主のエンジンを閉じて起動し直します。窓には、いちばん新しい途中保存のファイル（`.dev`・`.dev2`・`.store` など、book の隣）と時刻が出ます。
- 「学習」→「途中保存から続ける…」：book より新しい途中保存があれば、それを読み込み、最後の学習の命令を同じ局面から続けます。最後の命令は `config.ini` の `[learn] last_command` に残ります。

## 学習の列

- 「学習」→「足りない進行をすべて学習の列に入れる」：book のタブの足りない進行それぞれを、その局面まで打つ → `book store` → 精度の基準の命令（X Y）の仕事にして列に入れます。
- 「学習の列を始める…」で順に行います。止めると、残りの仕事は列に残ります。「学習の列を消す」で空にします。
- 命令の列の `learn <命令>` でも列に入れられます（[10. 命令の列](10-scripts.md)）。

## 学習の設定

「学習」→「学習の設定…」：主のエンジンに送る設定です（`config.ini` の `[learn_options]`）。

| 項目 | 意味 |
|---|---|
| 同時に広げる数・同時に入れる棋譜の数 | 数か auto（空はエンジンの設定のまま） |
| 時間ごとの保存（分）・周ごとの保存 | 途中保存の間隔（時間は 0 で時間では保存しない、周は 0 で終わったときだけ） |
| 乱数の種・毎回同じ book にする | 同じ book を作り直したいとき |
| Leaf の計算し直しの回数の上限 | 変わらなかった回で終わる |
| merge の後に .mrg へ・store の後に .store へ保存 | on か off |

## 注意

- book を変える命令の後は、エンジンを閉じるときに book のファイルが保存されることがあります。大事な book は写しを取ってから学習してください。
- 学習の速さとメモリはエンジンと book の大きさで決まります。大きな book の学習は時間がかかります。
