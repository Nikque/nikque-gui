# 2. 置き方と起動

[目次](README.md) ・ 前：[1. はじめに](01-introduction.md) ・ 次：[3. 画面](03-screen.md)

## 置き方

1. 配布の ZIP（`nikque-gui-0.4.10.zip`）を好きな場所に展開します。インストールは要りません。
2. `nikque-gui.exe` を起動します。

フォルダの中身：

| ファイル | 中身 |
|---|---|
| `nikque-gui.exe` | GUI |
| `config.ini` | 設定（[11. 設定](11-settings.md)） |
| `lang\*.txt` | 画面の言葉（日本語・English・简体中文・繁體中文） |
| `engines\nikque` | C 版の Edax v4.5.5-nikque.33 |
| `engines\newedax` | Heath（旧名 newedax）の heath.20（C++ 版、64 枠の版） |
| `readme.txt` | 短い説明 |

- どちらのエンジンのフォルダにも、次のファイルがあります。
  - `wEdax-x86-64-v4.exe`（AVX-512）
  - `wEdax-x86-64-v3.exe`（AVX2）
  - `wEdax-x86-64.exe`（その他の x64）
  - `data\eval.dat`
- 0.2.0 までの `config.ini`（系列の名前が `[nikque18]`）も、そのまま読めます。読み込むと `[nikque]` に直して保存します。

## Mac（試しの版）

0.4.3 から、Mac 版（`nikque-gui-0.4.10-mac.zip`）があります。

- macOS 13 以上の Mac で動きます。Apple シリコンと Intel のどちらでも動きます。
- まだ試しの版です。動きのおかしい所があれば知らせてください。

1. ZIP を好きな場所に展開します。
2. 初めに一度だけ、「ターミナル」で次のコマンドを実行します。署名していないアプリなので、そのままでは macOS に止められるためです。

   ```
   xattr -dr com.apple.quarantine ~/Downloads/nikque-gui-0.4.10-mac
   ```

   `~/Downloads/nikque-gui-0.4.10-mac` は、展開したフォルダの場所に替えてください。

   これで、フォルダの中のアプリとエンジンがすべて開けるようになります。
3. `nikque GUI.app` を開きます。

フォルダの中身は Windows 版と同じです。`nikque GUI.app` の隣に `config.ini`・`lang`・`engines` があります。

- どちらのエンジンのフォルダにも、次のファイルがあります。`exe=auto` なら、Mac に合わせて選びます。
  - `mEdax-arm64`（Apple シリコン）
  - `mEdax-x64-modern`（Intel）
  - `data/eval.dat`
- nikque 系のエンジンは、v4.5.5-nikque.33 の Release の ZIP に入っているものです。
- Heath 系のエンジンは、heath.20 のタグのソース（64 枠）から、この配布版のためにビルドしたものです（`engines/newedax/SOURCE.txt`）。heath.20 の Release に、Mac 用が無いためです。
- ファイルの場所は `/` で区切ります。`config.ini` の `dir=` などに書く場所も、Mac の書き方で書きます（例：`/Users/名前/books/book.dat`）。
- キー操作では、Windows の Ctrl の代わりに Command（⌘）を使います。例えば、Command+C で棋譜をコピーします。
- 右クリックは、トラックパッドの 2 本指のクリックか、control を押しながらのクリックです。
- 空白を含む名前のファイルは、エンジンに直接渡せません。そのときは、GUI が一時フォルダを通して渡します。ログにもそう出ます。
- アプリを「アプリケーション」フォルダに移すときは、`config.ini`・`lang`・`engines` もアプリと同じフォルダに置いてください。

## Linux（試しの版）

0.4.4 から、Linux 版（`nikque-gui-0.4.10-linux.tar.gz`）があります。

- x86-64 の Ubuntu 22.04 以上で動きます。同じころ以降のほかのディストリビューションでも動く見込みです。
- 画面の部品は GTK 3 です。
- まだ試しの版です。動きのおかしい所があれば知らせてください。

1. 好きな場所に展開します。

   ```
   tar -xzf nikque-gui-0.4.10-linux.tar.gz
   ```

2. 中の `nikque-gui` を起動します。ファイルマネージャーから開くか、端末で `./nikque-gui` を実行します。

フォルダの中身は Windows 版と同じです。`nikque-gui` の隣に `config.ini`・`lang`・`engines` があります。

- GTK 3 は、ふつうのデスクトップ版の Ubuntu には初めから入っています。入っていないときは、`sudo apt install libgtk-3-0` でインストールします。
- 日本語・中国語の文字は、システムのフォント（Noto Sans CJK など）で表示します。文字が四角になるときは、`sudo apt install fonts-noto-cjk` でインストールします。
- どちらのエンジンのフォルダにも、次のファイルがあります。`exe=auto` なら、CPU に合わせて選びます。
  - `lEdax-x86-64-v4`（AVX-512）
  - `lEdax-x86-64-v3`（AVX2）
  - `lEdax-x86-64`（その他の x64）
  - `data/eval.dat`
- エンジンは、タグのソースから、この配布版のためにビルドしたものです（`engines/*/SOURCE.txt`）。使ったタグは、v4.5.5-nikque.33 と、heath.20 の 64 枠です。
- nikque.33 の Release の ZIP にある Linux 用は、Ubuntu 24.04 以上向けです。heath.20 の Release には、Linux 用がありません。
- ファイルの場所は `/` で区切ります。`config.ini` の `dir=` などに書く場所も、Linux の書き方で書きます（例：`/home/名前/books/book.dat`）。
- 空白を含む名前のファイルは、エンジンに直接渡せません。そのときは、GUI が一時フォルダを通して渡します。ログにもそう出ます。
- フォルダを移すときは、`nikque-gui`・`config.ini`・`lang`・`engines` をいっしょに移してください。

## Android（試しの版）

0.4.4 から、Android 版（`nikque-gui-0.4.10-android.apk`）があります。

- Android 10 以上の、arm64 の端末向けです。今のほとんどの電話とタブレットが、arm64 の端末です。
- まだ試しの版です。エミュレーターで動きを確かめただけで、実機ではまだ確かめていません。
- 動きのおかしい所があれば知らせてください。

1. APK を端末にダウンロードして開き、インストールします。ストアの外のアプリなので、初めに「提供元不明のアプリ」のインストールを許可するよう求められます。
2. 「nikque GUI」を開きます。初めての起動と、版を上げた後の最初の起動では、ファイルの準備に少し時間がかかります。

画面と操作：

- 上にボタンの列があります。
  - 「メニュー」：Windows 版のメニューバーの中身が、一覧で出ます。
  - 最初へ・1 手戻る・1 手進む・最後へ。
- 縦に持つと、上に盤、下にパネルが出ます。パネルには、候補手・book・棋譜・リスト・木のタブと、グラフがあります。
- 横に持つと、Windows 版と同じ並びです。
- タップはクリックです。マスをタップすると、そこに打ちます。
- 長押しは右クリックです。盤の上では、1 手戻ります。しおりの絵では、メニューが出ます。
- 2 本の指を上下に動かすと、スクロールします。
- 端末の「戻る」を押すと、終了するかを尋ねます。終了すると、設定を保存してエンジンを閉じます。

この版に無いもの：

- book の学習と整理
- 棋譜リスト
- スクリプト
- ファイルを選ぶ機能（book を開く、書き出し、画像の保存など）
- 棋譜の欄への手入力（「コピー」「貼り付け」のボタンは使えます）
- お持ちの book を置く方法（まだありません。エンジンが初期局面だけの小さな book を作ります）

初めの 4 つは、メニューにも出ません。

そのほか：

- エンジンは両方とも入っています。v4.5.5-nikque.33 と heath.20 の Release の ZIP にある `aEdax-arm64-v8a` です。
- エンジンは別のプログラムとして動きます。
- Heath は、エンジン 1 つで約 160〜275 MB のメモリを使います。メモリの少ない端末では、「エンジン」→「nikque 系」に切り替えると軽くなります。
- 別のアプリに切り替えている間も、エンジンが考え続けることがあります。使い終わったら、「戻る」で終了してください。
- APK は試し用の鍵で署名しています。次の版を上書きインストールできないとき（鍵が違うと表示されるとき）は、一度アンインストールしてからインストールしてください。
- アンインストールすると、設定は初めに戻ります。

## エンジンの系列を選ぶ

「エンジン」→「nikque 系」・「Heath 系（旧名 newedax）」で切り替えます。

- 初めて起動したときは Heath 系です。0.4.0 までは nikque 系でした。
- 選んだ系列は `config.ini` に保存され、次の起動でも使われます。
- どちらも同じ book の解析のコマンドを持ち、同じ結果を返します。
- Heath は、newedax.13 から、新しく学習し直した評価関数（64 枠）を使います。その `eval.dat` は約 108 MB です。nikque の `eval.dat` とは別のものです。
- Heath の `eval.dat` は、エンジンと同じ版の配布の ZIP に入っているものを使ってください。
  - heath.17〜heath.19 の64枠版は同じファイルを使います。eval2・nikque の `eval.dat` を読ませると、エンジンは動きますが、評価が正しくありません。
  - そのときは、GUI がメッセージで知らせます（[12. 困ったときは](12-troubleshooting.md)）。
- 48 枠の版は付いていません。Heath の Release の `edax-4.5.5-heath.20-48.zip` です。使うときは、次のようにします。
  1. その ZIP を、別のフォルダに展開します。
  2. `config.ini` の `[newedax]` の `dir=` に、展開した `bin` のフォルダを書きます。`[newedax]` は Heath の設定です。

  48 枠の exe には、同じ ZIP の 48 枠の `eval.dat` を使ってください。取り違えると、メッセージは出ずに、評価が正しくなくなります。
- メモリの目安：
  - heath.20 は、エンジン 1 つで約 160 MB（`wEdax-x86-64.exe`）〜約 275 MB（AVX-512 の `wEdax-x86-64-v4.exe`）を使います。
  - GUI はエンジンを最大 5 つ起動します。メイン・探索用・ツール用・対局用・比較用です。すべて Heath だと、約 0.8〜1.4 GB になります。
  - 置換表を大きくしたり、スレッドを増やしたりすると、さらに増えます。book の大きさは、これとは別に足されます。
- book の形式は変わっていません。前の版で使っていた book は、そのまま読めます。
- ただし、前の版で学習した book の値は、前の評価関数でつけたものです。

## book を置く

book は付いていません。次のどちらかの方法で使います。

- お持ちの `book.dat` を、エンジンのフォルダの `data\book.dat` に置く。
- 「book」→「別の book を開く…」で選ぶ。ファイルをウィンドウにドラッグ＆ドロップしても開けます。`config.ini` の `[nikque]`・`[newedax]` の `book=` に書いても同じです。

book が無いと、エンジンは `data\book.dat` に初期局面だけの小さな book を作ります。後でお持ちの book に置き換えてかまいません。

- book のファイルはエンジンが読み書きします。学習や book を変えるコマンドの後は、エンジンを閉じるときに book のファイルが保存されることがあります。大事な book は先にコピーを取ってください。
- nikque 系列は、Heath の book の形式 2（`NEDXBOOK`）を読めません。その book を開くと、メッセージが出ます。

## すでにあるエンジンを使う

`config.ini` の `[nikque]`・`[newedax]` の `dir=` に、エンジンのフォルダを書きます。

- `exe=auto` なら、CPU に合わせて exe を選びます。
- `exe=` にファイル名を書けば、そのファイルを使います。

GUI は book の解析のコマンド（`book moveinfo` など）を使います。そのため、v4.5.5-nikque.19・v4.5.5-newedax.4 以降のエンジンが必要です。

- 古いエンジンでは、上の帯に「book の解析なし（古いエンジン）」と出ます。book の値・木・book タブは表示されません。探索の評価値は表示されます。
- book を軽くする機能（`book reduce`）は v4.5.5-nikque.20・v4.5.5-newedax.5 からです。それより前のエンジンでは、メッセージを出して何もしません。

## 言語

「設定」→「言語」で選びます。中国語の画面の言葉は機械翻訳です。

## ファイル名と文字

- エンジンは、ファイル名をシステムの文字コード（日本語の Windows では Shift_JIS）で読みます。
- エンジンに渡せない名前のときは、GUI は次のどちらかにします。渡せない名前とは、その文字コードに無い文字を含む名前や、長すぎる名前です。
  - フォルダを短い名前（8.3 形式）にして渡す。
  - メッセージを出して渡さない。
- book のファイル名そのものは、短い名前にしません。エンジンは book を保存するとき、渡された名前で書くためです。
- book のファイル名に、システムの文字コードに無い文字（日本語の Windows ではハングルなど）があると開けません。名前を変えてください。
