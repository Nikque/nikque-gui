# 12. 困ったときは

[目次](README.md) ・ 前：[11. 設定](11-settings.md)

| 様子 | 理由と対処 |
|---|---|
| 上の帯に「エンジンなし」 | エンジンの exe か `eval.dat` が見つかりません。ログに探した場所が出ます。`config.ini` の `[nikque18]`・`[newedax]` の `dir=`・`exe=` を確かめてください |
| 上の帯に「book の解析なし（古いエンジン）」 | エンジンが v4.5.5-nikque.19・newedax.4 より前の版です。付いているエンジンか、それ以降の版を使ってください |
| 上の帯に「book の場所を渡せません」 | book の名前が長すぎるか、システムの文字コードに無い文字があり、短い名前でも渡せません。book を短い名前の場所に写すか、名前を変えてください |
| 「book を読み込み中」が長い | 大きな book は読み込みに時間がかかります（エンジンが読みます） |
| book のタブが「数えています…」のまま | 大きな book の序盤では、局面の数を数えるのに時間がかかります。「解析」→「book の局面数も数える」を切ると速くなります |
| 「このファイルの場所は、エンジンに渡せません」 | 空白か読めない文字があり、短い名前も一時フォルダも使えませんでした。別の場所を選んでください |
| 「命令に、エンジンの読めない文字があります」 | 命令の欄・命令の列の命令に、システムの文字コードに無い文字があります。その命令は送りませんでした |
| 学習が終わらない | 大きな book の学習は長くかかります。「学習」→「学習を止める…」で止め、後で「途中保存から続ける…」で続けられます |
| book のファイルが変わった | 学習や book を変える命令の後は、エンジンを閉じるときに book が保存されます。写しを取ってから行ってください |
| 評価値が出ない | H で隠していないか、「解析」→「評価値を出す」を確かめてください。終局した局面には出ません |
| 画面の言葉が違う | 「設定」→「言葉」 |
| キーを変えたい | `config.ini` の `[keys]`（GUI を閉じてから直す） |

ログ（L）に、エンジンの答えと GUI の知らせが出ます。「表示」→「ログを書き出す…」で保存できます。
