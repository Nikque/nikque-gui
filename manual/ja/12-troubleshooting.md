# 12. 困ったときは

[目次](README.md) ・ 前：[11. 設定](11-settings.md)

| 様子 | 理由と対処 |
|---|---|
| 上の帯に「エンジンなし」 | エンジンの exe か `eval.dat` が見つかりません。ログに探した場所が出ます。`config.ini` の `[nikque]`・`[newedax]` の `dir=`・`exe=` を確かめてください |
| 上の帯に「book の解析なし（古いエンジン）」 | エンジンが v4.5.5-nikque.19・newedax.4 より前のバージョンです。付いているエンジンか、それ以降のバージョンを使ってください |
| 「このエンジンには book reduce のコマンドがありません」 | book を軽くする機能は v4.5.5-nikque.20・newedax.5 からです。付いているエンジンを使ってください |
| 上の帯に「book の場所をエンジンに渡せません」 | book の名前が長すぎるか、システムの文字コードに無い文字があり、短い名前でも渡せません。book を短い名前の場所にコピーするか、名前を変えてください |
| 「book を読み込み中」が長い | 大きな book は読み込みに時間がかかります（エンジンが読みます）。その間も book の評価値は出ます。精度・うみがめ数などの解析は読み込みの後に出ます。読み込みが終わると、下のログに book の場所と大きさが出ます |
| book タブが「数えています…」のまま | 大きな book の序盤では、局面の数を数えるのに時間がかかります。「解析」→「book の局面数も数える」を切ると速くなります |
| 精度の計算が重い・遅い | 「解析」→「book の精度を計算する」を切ると、book の評価値だけを出します。局面を動かせば、前の局面の計算は止まり、新しい局面の計算が始まります。今の計算だけを止めたいときは「入出力」→「裏の処理を止める」 |
| 手にマウスを乗せると、ほかのマスに石と番号が出る | 読み筋の表示です。「表示」→「マウスを乗せた手の読み筋を盤に表示する」で切れます（初めは切です） |
| 「このファイルの場所は、エンジンに渡せません」 | 空白か読めない文字があり、短い名前も一時フォルダも使えませんでした。別の場所を選んでください |
| 「コマンドに、エンジンの読めない文字があります」 | コマンドの入力・スクリプトのコマンドに、システムの文字コードに無い文字があります。そのコマンドは送りませんでした |
| 学習が終わらない | 大きな book の学習は長くかかります。「学習」→「学習を中止…」で止め、後で「途中保存から再開…」で続けられます |
| book のファイルが変わった | 学習や book を変えるコマンドの後は、エンジンを閉じるときに book が保存されます。コピーを取ってから行ってください |
| 評価値が出ない | H で隠していないか、「解析」→「評価値を表示する」を確かめてください。終局した局面には出ません |
| 画面の言葉が違う | 「設定」→「言語」 |
| キーを変えたい | `config.ini` の `[keys]`（GUI を閉じてから直す） |

- ログ（L）に、エンジンの応答と GUI のメッセージが出ます。
- 「表示」→「ログを保存…」で保存できます。
