# 12. 困ったときは

[目次](README.md) ・ 前：[11. 設定](11-settings.md)

| 様子 | 理由と対処 |
|---|---|
| 上の帯に「エンジンなし」 | エンジンの exe か `eval.dat` が見つかりません。ログに探した場所が出ます。`config.ini` の `[nikque]`・`[newedax]` の `dir=`・`exe=` を確かめてください |
| 「評価関数のファイル（eval.dat）は、このエンジンの版のためのものではありません」 | newedax.13 に、前の版の newedax・eval2・nikque の `eval.dat` を読ませています。エンジンは動きますが、評価が正しくありません。ログにはエンジンの `WARNING` の行も出ます。付いている `engines\newedax\data\eval.dat`（エンジンと同じ版の配布物のもの）を使ってください。`config.ini` の `[newedax]` の `eval=`・`dir=` を確かめてください（メッセージは GUI を起動している間に 1 回だけ出ます。ログと下の行には毎回出ます） |
| 上の帯に「book の解析なし（古いエンジン）」 | エンジンが v4.5.5-nikque.19・newedax.4 より前のバージョンです。付いているエンジンか、それ以降のバージョンを使ってください |
| 「このエンジンには book reduce のコマンドがありません」 | book を軽くする機能は v4.5.5-nikque.20・newedax.5 からです。付いているエンジンを使ってください |
| 「このメインエンジンは、deviate の進行の書き出しを持っていません」 | deviate がたどる進行の書き出しは v4.5.5-nikque.26・eval2.14・newedax.11 からです。前の版のエンジンは書き出しの語を読まずに book を広げてしまうので、GUI は送りません。付いているエンジンを使ってください |
| 「メインエンジンが book を読み込んでいるので、deviate の進行の書き出しを持っているかがまだ分かりません」 | エンジンは book を読み終えてから、書き出しを持っているかを答えます。下のログに book の場所と大きさが出てから、もう一度行ってください（スクリプトも同じです） |
| 上の帯に「book の場所をエンジンに渡せません」 | book の名前が長すぎるか、システムの文字コードに無い文字があり、短い名前でも渡せません。book を短い名前の場所にコピーするか、名前を変えてください |
| 「book を読み込み中」が長い | 大きな book は読み込みに時間がかかります（エンジンが読みます）。その間も book の評価値は出ます。精度・うみがめ数などの解析は読み込みの後に出ます。読み込みが終わると、下のログに book の場所と大きさが出ます |
| book タブが「数えています…」のまま | 大きな book の序盤では、局面の数を数えるのに時間がかかります。「解析」→「book の局面数も数える」を切ると速くなります |
| 精度の計算が重い・遅い | 「解析」→「book の精度を計算する」を切ると、book の評価値だけを出します。局面を動かせば、前の局面の計算は止まり、新しい局面の計算が始まります。今の計算だけを止めたいときは「入出力」→「裏の処理を止める」 |
| 精度やうみがめ数が出るまでに時間がかかる | book の評価値は先に出ます。精度・うみがめ数・局面数は、棋譜の局面の評価値がそろった後に計算します |
| 学習中や、手順の推定・棋譜リストへの読み込み・最善手順の書き出し・deviate がたどる進行の書き出し・book を軽くする前の数えの間、精度などが出ない | これらの処理の間、エンジンは book の解析に答えられません。評価値は book のファイルから直接読んで出し、処理が終わると精度などを計算します。学習中の評価値は、最後に保存された book の値です。book を保存している間（「book」→「保存する」、コマンドの `book save` など）は、保存を妨げないように book のファイルも読まないので、まだ出ていない評価値は保存が終わってから出ます |
| 手にマウスを乗せると、ほかのマスに石と番号が出る | 読み筋の表示です。「表示」→「マウスを乗せた手の読み筋を盤に表示する」で切れます（初めは切です） |
| 「このファイルの場所は、エンジンに渡せません」 | 空白か読めない文字があり、短い名前も一時フォルダも使えませんでした。別の場所を選んでください |
| 「コマンドに、エンジンの読めない文字があります」 | コマンドの入力・スクリプトのコマンドに、システムの文字コードに無い文字があります。そのコマンドは送りませんでした |
| 学習が終わらない | 大きな book の学習は長くかかります。「学習」→「学習を中止…」で止め、後で「途中保存から再開…」で続けられます |
| book のファイルが変わった | 学習や book を変えるコマンドの後は、エンジンを閉じるときに book が保存されます。コピーを取ってから行ってください |
| 閉じるときなどに「メインエンジンが book を保存して終了するのを待っています」と出て、なかなか閉じない | book を変えるコマンドの後は、エンジンが終了するときに book を保存します。大きな book では数分かかるので、時間の上限なしで待ちます（その間もウィンドウは使え、下の行に経った時間が出ます）。保存が終わると、続きの処理（閉じる、book を開く など）を行います。もう一度閉じると保存を打ち切るかを尋ねますが、打ち切ると学習の結果が book のファイルに入りません（[6. 学習](06-learning.md) の注意） |
| 評価値が出ない | H で隠していないか、「解析」→「評価値を表示する」を確かめてください。終局した局面には出ません |
| 画面の言葉が違う | 「設定」→「言語」 |
| キーを変えたい | `config.ini` の `[keys]`（GUI を閉じてから直す） |

- ログ（L）に、エンジンの応答と GUI のメッセージが出ます。
- 「表示」→「ログを保存…」で保存できます。
