# nikque GUI ユーザーマニュアル

[English](../en/README.md)

nikque GUI は、オセロのエンジン Edax v4.5.5-nikque（C 版）と newedax（C++ 版）のための Windows の GUI です。盤の上に全部の合法手の評価値と book の精度を出し、book の解析・学習・対局・棋譜の整理を画面から行えます。

![候補手のタブ](../images/ja-01-moves.png)
