# 8. 棋譜・リスト・しおり

[目次](README.md) ・ 前：[7. 対局](07-play.md) ・ 次：[9. ツールと棋譜のファイル](09-tools.md)

## 棋譜のコピー・貼り付け

- 「入出力」→「棋譜をコピー（今の局面まで）」・「棋譜を貼り付け」。
- キーでは Ctrl+C、Ctrl+V です。Ctrl+V は 2 回押します。
- 貼り付けられる形式：
  - 座標の列（`f5d6c3…`）
  - 盤面の文字列（64 マスと手番）
  - ビットボード
  - ブログの PARAM の形式
- 「棋譜を固定する」：今の棋譜を固定します。その後に打った棋譜を固定した棋譜と比べ、悪手に赤枠を付け、違う手の所をマークします。

## 局面の文字列とビットボード

「入出力」→「局面の文字列・ビットボード」で、次の形式をコピーします。

- 盤面の文字列
- 問題の形式（obf）
- ビットボード（10 進・16 進・Ntest の形式）

「局面を取り込む…」で読み込みます。

- 10 進・16 進は「黒 白 手番」です（a1 が 0 ビット目、h8 が 63 ビット目、手番は X か O）。
- Ntest の形式は「空き 手番の側の石 手番」です。

## 盤面配置

E で始め、もう一度 E か Enter で決めます。配置中の操作：

| 操作 | 働き |
|---|---|
| 左クリック | 黒 → 白 → 空き |
| 右クリック | 空き |
| T | 手番 |
| Delete | 全部消す |
| I | 初期配置 |
| Esc | やめる |

## 盤から手順を推定する

「入出力」→「盤から手順を推定する（20 手目まで）」：今の盤の局面に着く手順を作ります。

1. まず、book の局面だけを通る手順を探します（`book findline`）。
2. 無ければ、book を使わずに探します。

見つからないときは、「手順を探しきれませんでした」か「この局面に着く手順はありません」と出ます。

## 棋譜リスト

1 行に 1 局を書いたテキストファイルです。

- `f5d6c3…` の形式
- `<64 マス> <X|O>;手順` の形式（別の最初の局面から）

リストタブに表示され、行を押すとその棋譜を開きます。

「入出力」→「棋譜リスト」のメニュー：

- 読み込む・追加する・保存する
- 今の棋譜をリストに追加
- book の進行をリストへ
- 並べ替える（短い順、同じ長さは手順の順）
- 同じ棋譜をまとめる
- 短くする（各棋譜を n 手まで）
- 並びを混ぜる（乱数の種）
- 向きをそろえる（初手を f5 に。後の対称な局面でも決まった向きに）
- 向きをばらばらにする（対称な局面で乱数）
- 前・次の棋譜（Ctrl+Shift+← →）
- 今の棋譜を読み込み直す・消す（Ctrl+Shift+↓ ↑）
- リストを空にする
- 何手目から表示するか

補足：

- 100 万局のリストも扱えます。
- 重い処理はバックグラウンドで行います。「入出力」→「裏の処理を止める」で止められます。
- 向きをそろえる・ばらばらにするを途中で止めると、それまでに向きを変えた棋譜は変えたまま残ります（同じ棋譜の別の向き）。

## 棋譜検索

「入出力」→「棋譜検索（今の局面が現れる棋譜）」：リストの中から、今の局面が現れる棋譜を探します。

- 向きの違う局面も含めて探します。
- 結果はリストタブに表示します。行を押すと、その局面を開きます。
- 「検索の結果を消す」で結果を消します。

## しおり

![しおりの列](../images/ja-08-bookmarks.png)

しおりは、棋譜とその中の局面を保存しておく機能です。グラフのすぐ上に、しおりを挟んだ局面の盤の絵が、古い順に左から並びます。

### しおりを挟む

- M で、今の局面にしおりを挟みます。メニューでは「対局」→「今の局面にしおりを挟む」です。「表示」→「しおり」の中にも同じ項目があります。
- 同じ棋譜でも、違う局面なら別のしおりになります。

### 自動のしおり

- 次のときは、それまでの棋譜に自動でしおりが挟まれます。
  - 新しい対局
  - 棋譜の貼り付け
  - 盤面配置
  - 手順の推定
- しおりの数に制限はありません。しおりは exe の隣の `kept.txt` に保存します。
- 自動のしおりは、同じ棋譜が続けて来ると、最後の局面へ移動して 1 つのままです。
- M で挟んだしおりは移動しません。同じ棋譜の別の局面なら、新しいしおりになります（0.2.1 から）。
- 0.2.0 までの `kept.txt` のしおりは、自動のものとして読みます。

### しおりの操作

- 絵を押すと、その棋譜のその局面へ行きます。
- 絵を右クリックすると、メニューが出ます。
  - 「選んだしおりの局面へ」
  - 「選んだしおりの棋譜と比べる」：固定の棋譜と同じ方法（悪手に赤枠、違う手の所をマーク）で比べます。
  - 「選んだしおりを消す」
- 絵にマウスを乗せると、いちばん下の行に、しおりの番号と手順が出ます。
- 「表示」→「しおり」→「しおりを全部消す…」で、すべてのしおりを消します。
- 「表示」→「しおり」→「しおりの列を表示する」で、列の表示・非表示を切り替えます。

## 画像

- 「入出力」→「スクリーンショット」（Ctrl+P）：exe の隣の `screenshots` フォルダに、画面を PNG で保存します。保存先は `config.ini` の `[view] screenshot_dir` で変えられます。
- 「盤の図を保存する（PNG）…」：盤だけの図を保存します。

## 定石名

exe の隣の `opening.ini`（付属）を読んで、盤の下に定石名を表示します（[画面](03-screen.md)）。

- テキストファイルで、1 行に `名前=手順` と書きます。
- 手順は、初手を f5 として書きます。
- 行の先頭の空白は、階層を見せるだけのものです。
- `//` で始まる行はコメントです。
- メモ帳などで編集できます。
- ほかのファイルを使うときは、`config.ini` の `[view] opening_file=` に書きます。
