# 9. ツールと棋譜のファイル

[目次](README.md) ・ 前：[8. 棋譜・リスト・しおり](08-games.md) ・ 次：[10. スクリプト](10-scripts.md)

## ツール用エンジン

「エンジン」のメニューのツールは、book を読まない「ツール用エンジン」で実行します。

- ツール用エンジンは、1 回ごとに起動します。
- 今の局面から実行します。
- 出力はログに出ます。
- その間も、メインエンジン（book の解析）と探索用エンジンは動きます。

| 項目 | エンジンのコマンド |
|---|---|
| 問題を解く… | `solve <obf のファイル>` |
| 速さを測る… | `bench <数>` |
| 手順・局面を数える… | `count games\|positions\|shapes <深さ>` |
| 手順を数える… | `perft <深さ>` |
| 手順の数を見積もる… | `estimate <数>` |
| ツールを止める | ツール用エンジンを閉じる |

## 棋譜のファイル（base）

「入出力」→「棋譜のファイル（base）」：棋譜のファイル（txt・ggf・sgf・pgn・wtb など）を、ツール用エンジンで処理します。

| 項目 | 中身 |
|---|---|
| 形式を変える（convert） | 別の形式のファイルに書く |
| 同じ対局をまとめる（unique） | 重なる対局を 1 つに |
| 共通の局面を数える（compare） | 2 つのファイルを比べる |
| 終盤の悪手を探す（check） | 空きマスの数を指定して確かめる |
| 終盤の悪手を直す（correct） | ファイルを書き換える |
| 未完の対局を打ち継ぐ（complete） | ファイルを書き換える |
| 局面を問題のファイルに書き出す（problem） | obf に |
| 局面を FEN で書き出す（tofen） | FEN に |

- ファイルを書き換えるコマンドは、始める前に確認します。
- 出力先に入力と同じファイルを選ぶと、実行しません。

## コマンドの入力

「エンジン」→「コマンドを入力（メインエンジンに送る）…」：Edax のコマンドを、メインエンジンに直接送ります。

- `|` で区切ると、複数のコマンドを送れます。
- 今の局面から実行します。終わるまで、book の解析は止まります。
- 最後に入力したコマンドは、`config.ini` の `[tools] last_command` に保存されます。
- コマンドは、エンジンが読める文字（システムの文字コード）に変換して送ります。読めない文字があるときは、送らずにメッセージを出します。
- 空白やエンジンが読めない文字を含むファイル名は、ここでは渡せません。次のどちらかを使ってください。
  - メニューの項目（ファイルを選ぶダイアログ）
  - スクリプトの `"…"`（[10. スクリプト](10-scripts.md)）

## ファイル名の受け渡し

エンジンは、ファイル名を空白で区切って読み、システムの文字コードで開きます。

ファイルを選ぶダイアログで選んだ名前に、空白や読めない文字があるときは、GUI は次のようにします。

- 短い名前（8.3 形式）にして渡します。
- 短い名前の無いドライブ（多くの D: など）では、一時フォルダにコピーして渡します。エンジンが書いたファイルは、処理の後に元の場所へ移動します（ログに出ます）。
