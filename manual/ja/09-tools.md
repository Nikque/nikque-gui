# 9. ツールと棋譜のファイル

[目次](README.md) ・ 前：[8. 棋譜・リスト・しおり](08-games.md) ・ 次：[10. スクリプト](10-scripts.md)

## ツール用エンジン

「エンジン」のメニューのツールは、book を読まない「ツール用エンジン」を 1 回ごとに起動して、今の局面から実行します。出力はログに出ます。メインエンジン（book の解析）と探索用エンジンは、その間も動きます。

| 項目 | エンジンのコマンド |
|---|---|
| 問題を解く… | `solve <obf のファイル>` |
| 速さを測る… | `bench <数>` |
| 手順・局面を数える… | `count games\|positions\|shapes <深さ>` |
| 手順を数える… | `perft <深さ>` |
| 手順の数を見積もる… | `estimate <数>` |
| ツールを止める | ツール用エンジンを閉じる |

## 棋譜のファイル（base）

「入出力」→「棋譜のファイル（base）」：棋譜のファイル（txt・ggf・sgf・pgn・wtb など）をツール用エンジンで扱います。

| 項目 | 中身 |
|---|---|
| 形式を変える（convert） | 別の形式のファイルに書く |
| 同じ対局をまとめる（unique） | 重なる対局を 1 つに |
| 共通の局面を数える（compare） | 2 つのファイルを比べる |
| 終盤の悪手を探す（check） | 空きマスの数を指定して確かめる |
| 終盤の悪手を直す（correct） | ファイルを書き換える |
| 未完の対局を打ち継ぐ（complete） | ファイルを書き換える |
| 局面を問題のファイルに書き出す（problem） | obf に |
| 局面を FEN で書き出す（tofen） | FEN に |

書き換えるコマンドは、始める前に確かめます。出力先に同じファイルを選ぶと断ります。

## コマンドの入力

「エンジン」→「コマンドを入力（メインエンジンに送る）…」：Edax のコマンドを直接、メインエンジンに送ります。`|` で区切ると複数のコマンドになります。今の局面から実行し、終わるまで book の解析は止まります。最後に入力したコマンドは `config.ini` の `[tools] last_command` に残ります。

- コマンドは、エンジンの読める文字（システムの文字コード）にして送ります。読めない文字があるときは送らずに知らせます。
- 空白やエンジンの読めない文字のあるファイルの名前は、ここでは渡せません。メニューの項目（ファイルを選ぶ窓）を使うか、スクリプトの `"…"`（[10. スクリプト](10-scripts.md)）を使ってください。

## 名前の受け渡し

エンジンは、ファイルの名前を空白で区切って読み、システムの文字コードで開きます。GUI は、ファイルを選ぶ窓で選んだ名前に空白や読めない文字があるときは、短い名前（8.3 形式）にして渡します。短い名前の無いドライブ（多くの D: など）では、一時フォルダにコピーして渡し、書かれたファイルは処理の後に元の場所へ移します（ログに出ます）。
