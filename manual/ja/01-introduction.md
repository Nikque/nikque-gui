# 1. はじめに

## できること

- **評価値**：全部の合法手の評価値を盤の上に出します。book にある手は book の値、ない手は探索の値です。
- **book の精度**：手ごとに、book がどこまで完成しているか（段階 0〜7）を色と効果で出します。
- **book の解析**：次の段階に足りない leaf までの手順、うみがめ数（その手の後の進行を全部知るために覚える端の数）、level ごとの局面数、最善の進行の数と書き出し、book の進行の木。
- **book の学習**：deviate・enhance・fill などの学習の命令を、今の局面から画面で行います。途中で止めて、途中保存から続けることもできます。
- **対局**：人とコンピューター、コンピューターどうし。持ち時間、序盤を book から選ぶ打ち方。
- **棋譜**：棋譜リスト（100 万局でも扱えます）、局面からの棋譜検索、控え、盤面配置、盤から手順の推定。
- **道具**：solve・bench・perft などのエンジンの道具、棋譜のファイルの変換（base）。
- **命令の列**：画面の操作を文字のファイルに並べて、順に行います。

## 仕組み

GUI はエンジンを子のプロセスとして起動し、文字の命令でやりとりします。book のファイルはエンジンが読み、GUI は読みません。エンジンは役目ごとに分けて起動します。

| エンジン | 役目 |
|---|---|
| 主のエンジン | book を読み、book の解析（裏のスレッド）と学習を行う |
| 探索だけのエンジン | book を読まずに、全部の手の評価値を探索する（`[engine] search=1`） |
| 道具のエンジン | solve・bench・base などを 1 回ごとに起動して行う |
| 対局のエンジン | 対局でコンピューターの手を考える（book を読まない） |
| 比べるエンジン | 比べるモードで、もう一方の系のエンジンが探索する |

そのため、学習の間も評価値は出続け、対局の間も盤の解析は続きます。

## 動く環境

64 ビット（x64）の Windows。作者が確かめたのは Windows 11 です。エンジンは CPU に合わせて AVX-512・AVX2・ほかの x64 の版から選びます（`exe=auto`）。
