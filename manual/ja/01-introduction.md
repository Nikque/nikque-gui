## できること

- **評価値**：全部の合法手の評価値を盤の上に出します。book にある手は book の値、ない手は探索の値です。
- **book の精度**：手ごとに、book がどこまで完成しているか（段階 0〜7）を色と効果で出します。
- **book の解析**：次の段階に足りない leaf までの手順、うみがめ数（その手の後の進行を全部知るために覚える端の数）、level ごとの局面数、最善の進行の数と書き出し、book の進行の木。
- **book の学習と整理**：deviate・enhance・fill などの学習のコマンドを、今の局面から画面で実行します。途中で中止して、途中保存から再開することもできます。`book deviate3 X Y` でたどれない局面を消して book を軽くすることもできます。
- **対局**：人とコンピューター、コンピューターどうし。持ち時間、序盤を book から選ぶ打ち方。
- **棋譜**：棋譜リスト（100 万局でも扱えます）、局面からの棋譜検索、しおり（局面の絵から選べます）、盤面配置、盤から手順の推定。
- **ツール**：solve・bench・perft などのエンジンのツール、棋譜のファイルの変換（base）。
- **スクリプト**：画面の操作をテキストファイルに並べて、順に実行します。

## 仕組み

GUI はエンジンを子のプロセスとして起動し、文字のコマンドでやりとりします。book のファイルはエンジンが読み、GUI は読みません。エンジンは役目ごとに分けて起動します。

| エンジン | 役目 |
|---|---|
| メインエンジン | book を読み、book の解析（裏のスレッド）と学習を行う |
| 探索用エンジン | book を読まずに、全部の手の評価値を探索する（`[engine] search=1`） |
| ツール用エンジン | solve・bench・base などを 1 回ごとに起動して実行する |
| 対局用エンジン | 対局でコンピューターの手を考える（book を読まない） |
| 比較用エンジン | 比較モードで、もう一方の系のエンジンが探索する |

そのため、学習の間も評価値は出続け、対局の間も盤の解析は続きます。

## 動く環境

64 ビット（x64）の Windows。作者が確かめたのは Windows 11 です。エンジンは CPU に合わせて AVX-512・AVX2・ほかの x64 の版から選びます（`exe=auto`）。
