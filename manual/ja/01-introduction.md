# 1. はじめに

[目次](README.md) ・ 次：[2. 置き方と起動](02-setup.md)

## できること

- **評価値**：すべての合法手の評価値を盤の上に表示します。book にある手は book の値、ない手は探索の値です。
- **book の精度**：手ごとに、その手の後の book がどこまで完成しているかを、段階 0〜7 として色と効果で表示します。
- **book の解析**：
  - 次の段階に足りない leaf までの手順
  - うみがめ数（その手の後の進行をすべて知るために覚える端の数）
  - level ごとの局面数
  - 最善の進行の数と書き出し
  - book の進行の木
- **book の学習と整理**：
  - deviate・enhance・fill などの学習のコマンドを、今の局面から画面で実行します。
  - 学習は途中で中止し、途中保存から再開できます。
  - `book deviate3 X Y` でたどれない局面を消して、book を軽くすることもできます。
- **対局**：人とコンピューター、コンピューターどうし。持ち時間を設定でき、序盤の手を book から選べます。
- **棋譜**：
  - 棋譜リスト（100 万局でも扱えます）
  - 局面からの棋譜検索
  - しおり（局面の絵から選べます）
  - 盤面配置
  - 盤から手順の推定
- **ツール**：solve・bench・perft などのエンジンのツールと、棋譜のファイルの変換（base）。
- **スクリプト**：画面の操作をテキストファイルに並べて、順に実行します。

## 仕組み

GUI はエンジンを子プロセスとして起動し、テキストのコマンドでやりとりします。book のファイルはエンジンが読みます。GUI が読むのは、エンジンが読み込んでいる間に、評価値に必要な局面の分だけです。

エンジンは役目ごとに分けて起動します。

| エンジン | 役目 |
|---|---|
| メインエンジン | book を読み、book の解析（バックグラウンドのスレッド）と学習を行う |
| 探索用エンジン | book を読まずに、全部の手の評価値を探索する（`[engine] search=1`） |
| ツール用エンジン | solve・bench・base などを 1 回ごとに起動して実行する |
| 対局用エンジン | 対局でコンピューターの手を考える（book を読まない） |
| 比較用エンジン | 比較モードで、もう一方の系列のエンジンが探索する |

そのため、学習の間も評価値は表示され続けます。対局の間も盤の解析は続きます。

## 動作環境

- 64 ビット（x64）の Windows。作者が動作を確認したのは Windows 11 です。
- エンジンは、CPU に合わせて AVX-512・AVX2・その他の x64 向けの版から選びます（`exe=auto`）。
