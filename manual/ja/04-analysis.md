## 評価値

- 局面が変わると、主のエンジンが book の解析を、探索だけのエンジンが全部の手の探索を始めます。値は手番の側から見た石差です。
- book にある手は book の値（book の Lv）、ない手は探索の値（「解析」→「評価の Lv」の深さ）です。
- 「解析」→「評価値を出す」（H で隠す）、「計算し直す」（覚えた値を捨てて頼み直す）。
- 「後ろから解析」：棋譜の局面を裏で後ろから読み、次の手の値で今の値を直します。直した値の Lv に ★ が付きます。

## book の精度の段階（0〜7）

手ごとに、その手の後の book がどこまでできているかを表します。上の帯の見本の玉にマウスを乗せると、色と意味が出ます。

| 段階 | 意味 |
|---|---|
| 0 | book にない手（探索の値） |
| 1 | book にあるが、最善の進行が完全読みまで届いていない |
| 2 | 最善の進行は完全読みまで届くが、最善に近い候補の leaf が残っている |
| 3〜7 | その手の後の局面から `book deviate x y` をしても何も増えない（既定の範囲は 3 が 1/1、4 が 2/2 … 7 が 5/5） |

- 「book」→「精度の基準」で、基準の命令を deviate・deviate2・deviate3 から選びます。段階 3〜7 の範囲（x/y）は「設定」→「調べる範囲…」で変えられます。
- 候補手のタブの「足りない」は、次の段階に足りない leaf の数です。book のタブで、その leaf までの手順（足りない進行）を見られます。

## うみがめ数

その手の後の進行（既定は両方の最善の手）を全部知るために覚える、いちばん少ない端の数です。黒・白それぞれ「黒:白」で出します。違う手順で着く同じ局面は 1 回だけ数えます。

「解析」→「うみがめ数」：

- 最善の進行だけ
- 石損 X・Y まで（調べる範囲の値）
- 出さない

「設定」→「調べる範囲…」で、評価値の範囲で数える形とたどる深さも選べます。範囲が広くて、いちばん少ないと言い切れない数には「≦」が付き、大きすぎる数は「大きすぎ」と出ます。

## 調べる範囲

右のパネルの上の「1 手の石損 X」と「合計 Y」は、精度の段階・足りない進行・うみがめ数（石損の形）・学習の命令で共通です。「設定」→「調べる範囲…」の窓では、ほかに精度の基準、段階ごとの範囲、うみがめ数の条件、評価の Lv、スレッドの数、ハッシュ表の大きさを変えられます（スレッドとハッシュ表を変えるとエンジンを起動し直します）。

## book の局面数

「解析」→「book の局面数も数える」を入れると、手ごとにその手の先の book の局面の数を数えます。大きな book では序盤ほど時間がかかります（数え終わるまで、book のタブの levels と最善の進行も後で出ます）。

## マスに出す数

「表示」→「マスに出す数」で、マスの左下に次のどれかを出します：book の局面数、Lv（L）、精度の段階（S）、うみがめ数（黒:白）。

## 比べるモード

「解析」→「比べるモード」：もう一方の系のエンジンを book なしの探索だけで起動し、候補手の表に「比べる」の列を足します。nikque 系と newedax 系の評価関数の違いを並べて見られます。
