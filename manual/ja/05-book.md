# 5. book

[目次](README.md) ・ 前：[4. 解析](04-analysis.md) ・ 次：[6. 学習](06-learning.md)

## book タブ

![book タブ](../images/ja-02-book.png)

book タブには次の情報を表示します。

- この局面が book にあるか。
- この局面から先の、level ごとの局面数（合計）。
- 最善の進行：
  - 両方が最善の手だけを打つ進行の数（端の局面の数）
  - そのうち、完全読みに届かない端の数
- 足りない進行：候補手タブか ↑↓ で選んだ手の先の、次の段階に足りない leaf までの手順。
  - 行を押すと、leaf を足す局面まで打ちます。
  - コンピューターとの対局中は動きません。

大きな book の序盤では、数えるのに時間がかかります（「数えています…」と表示）。

## 木の表示

![木タブ](../images/ja-03-tree.png)

「book」→「木を表示する」か、木タブで表示します。今の局面から先の book の手（リンク）を、開閉できる木で並べます。

- 各行の内容：打つ側の石の色、手、評価値（打つ側から見た book の値）、精度の段階、うみがめ数、Lv。
- leaf（book の局面からの、まだ book にない最善の手）は薄い行で表示します。leaf の行は開けません。
- 行を押すと、その局面へ進んで、その段を開きます。
- ▸ / ▾ を押すと、その段だけを開く・閉じます。
- 盤で根より先へ進む間は、木はそのままです。今の局面の行に色が付きます。
- 根より前に戻るか別の棋譜にすると、そこが新しい根になります。
- 行が多すぎるときは、途中までを表示してメッセージを出します。開いた所を閉じてください。

## 書き出し

- 「book」→「足りない進行を書き出す…」：
  - book タブに出ている足りない進行を、テキストファイルに書き出します。
  - 1 行に 1 本です（最初の局面からの手順と、足す leaf の手）。
  - 学習キューにまとめて入れることもできます（[6. 学習](06-learning.md)）。
- 「book」→「最善の進行を書き出す…」：
  - 今の局面から、両方が最善（または損失（石数）の幅まで）の手だけを打つ進行を、端までの手順で書き出します。1 行に 1 本です。
  - 選べる項目：石損、深さ、完全読みの局面で止めるか、書き出す端（すべての端か、完全読みに届かない端だけか）。
- 「入出力」→「棋譜リスト」→「book の進行をリストへ…」：同じ進行を、ファイルではなく棋譜リストに入れます。

## book の中身をログに表示

「book」→「book の中身をログに表示」で、次のどれかをログに表示します。

- book 全体の情報（`book info`）
- 数の内訳（`book stats`）
- 今の局面の中身（`book show`）

## 別の book、読み込み直す

- 「book」→「別の book を開く…」、「最近の book」：メインエンジンを再起動して読み込みます。ファイルをウィンドウにドラッグ＆ドロップしても開けます。
- 「book」→「book を読み込み直す」：book のファイルを GUI の外で変えたときに使います。
- 「book」→「book を使う」（B）：オフにすると book の値を表示せず、探索の値だけにします。

## book の整理

「book」→「book の整理・書き出し」のメニュー：

| 項目 | エンジンのコマンド |
|---|---|
| 保存する・別の名前で保存する | `book save` |
| 新しい空の book | `book new` |
| book の深さを変える | `book depth` |
| 局面を問題の形式でログに表示 | `book problem` |
| 別の book を取り込む | `book merge` |
| 今の局面から先だけを残す | `book subtree` |
| 片方が最善を打つ変化だけを残す | `book prune` |
| deviate3 X Y でたどれない局面を消して軽くする | `book reduce`（下） |
| テキストファイルに書き出す・読み込む | `book export`・`book import` |
| 最善の手順を棋譜に書き出す | `book extract` |

subtree・prune・reduce・import・new など、book を変えるコマンドの後は、エンジンを閉じるときに book のファイルが上書きされることがあります。このことは確認のウィンドウにも出ます。先にコピーを取ってください。

## book を軽くする（book reduce）

「book」→「book の整理・書き出し」→「deviate3 X Y でたどれない局面を消して軽くする（book reduce）…」。

指定の局面から `book deviate3 X Y` でたどれる局面だけを残し、ほかを消して book を小さくします。これは v4.5.5-nikque.20・newedax.5 からのエンジンの機能です。

### 手順

1. ウィンドウで、次の値を選びます。
   - 1 手の石損の上限 X（0〜129）
   - 石損の合計の上限 Y（0〜254）
   - どこから（初期局面から・今の局面から）

   X・Y の初期値は「調べる範囲」の値です。ふつうは初期局面からにします。今の局面からにすると、初期局面からここまでの局面も消えます。
2. GUI は先にエンジンに局面を数えさせます（`book reducecount`。book は変えません）。残る局面と消える局面の数を、ウィンドウに表示します。
3. 「OK」を押すと、学習と同じ方法で `book reduce X Y` を実行します。終わると、残した局面と消した局面の数がログに出ます。

### 残る局面

- 残るのは、指定の局面と、そこから「1 手の損失（石数）が X 以下、損失の合計が Y 以下」の手でたどれる局面です。
- この範囲は、`book deviate3 X Y` が広げる局面を探すときにたどる範囲と同じです。
- 残った局面の評価値は、先に計算し直した後の値から変わりません。

### 実行しないとき

次のときは、book を軽くしません。

- 数えている間や、数え終わってウィンドウが出る前に「入出力」→「裏の処理を止める」を選んだとき。
- エンジンが閉じたとき（book やエンジンを切り替えたときを含む）。
- ウィンドウを出している間にエンジンが閉じたとき。このときは「OK」を押しても実行しません（0.2.1 から）。

次のときは、メッセージを出して何もしません。

- 指定の局面から先の book が壊れているとき（v4.5.5-nikque.21・newedax.6 からのエンジン）。壊れているとは、すでに石のあるマスへの手や、同じ局面に戻る手のつながりがある状態です。
- このコマンドを知らない古いエンジン（nikque.19・newedax.4 まで）のとき。

### 数えた結果の再利用

v4.5.5-nikque.22・newedax.7 からのエンジンは、数えた後に book が変わっていなければ、数えた結果を使います（エンジンの設定 `book-reduce-reuse`）。

- 「OK」の後は、数えた結果で残す局面を決め、数え直しません。
- 大きな book ほど、「OK」の後の処理が短くなります。

### 元の book を残す

消した後の book は、エンジンを閉じると book のファイルに保存されます。元の book を残したいときは、次のどちらかにします。

- 先にファイルのコピーを取る。
- 「別の名前で保存する…」で保存してから、「book を読み込み直す」で元に戻す。

### スクリプトから

スクリプトでは `book reduce X Y`（今の局面からは `book reduce X Y here`）を使います。確認のウィンドウを出さずに実行します（[10. スクリプト](10-scripts.md)）。
