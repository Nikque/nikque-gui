# 5. book

## book タブ

![book タブ](../images/ja-02-book.png)

- この局面が book にあるか。
- この局面から先の、level ごとの局面数（合計）。
- 最善の進行：両方が最善の手だけを打つ進行の数（端の局面の数）と、そのうち完全読みに届かない端の数。
- 足りない進行：候補手タブか ↑↓ で選んだ手の先の、次の段階に足りない leaf までの手順。行を押すと、leaf を足す局面まで打ちます（コンピューターとの対局中は動きません）。

大きな book の序盤では、数えるのに時間がかかります（「数えています…」）。

## 木の表示

![木タブ](../images/ja-03-tree.png)

「book」→「木を表示する」か、木タブ。今の局面から先の book の手（リンク）を、開け閉めできる木で並べます。

- 各行：打つ側の石の色、手、評価値（打つ側から見た book の値）、精度の段階、うみがめ数、Lv。
- leaf（book の局面からの、まだ book にない最善の手）は薄い行で出し、開けません。
- 行を押すと、その局面へ進んでその段を開きます。▸ / ▾ を押すと、その段だけを開く・閉じます。
- 盤で根より先へ進む間は木がそのままで、今の局面の行に色が付きます。根より前に戻るか別の棋譜にすると、そこが新しい根になります。
- 行が多すぎるときは途中までにして知らせます。開いた所を閉じてください。

## 書き出し

- 「book」→「足りない進行を書き出す…」：book タブに出ている足りない進行を、1 行 1 本（最初の局面からの手順と、足す leaf の手）でテキストファイルに書き出します。学習キューにまとめて入れることもできます（[6. 学習](06-learning.md)）。
- 「book」→「最善の進行を書き出す…」：今の局面から、両方が最善（または石損の幅まで）の手だけを打つ進行の端までの手順を、1 行 1 本で書き出します（石損・深さ・完全読みの局面で止めるか・全部か完全読みに届かない端だけか、を選べます）。
- 「入出力」→「棋譜リスト」→「book の進行をリストへ…」：同じ進行を、ファイルではなく棋譜リストに入れます。

## book の中身をログに表示

「book」→「book の中身をログに表示」：book 全体の情報（`book info`）、数の内訳（`book stats`）、今の局面の中身（`book show`）。

## 別の book、読み込み直す

- 「book」→「別の book を開く…」（窓にファイルを落としても）、「最近の book」。メインエンジンを再起動して読み込みます。
- 「book」→「book を読み込み直す」：ファイルを外で変えたとき。
- 「book」→「book を使う」（B）：切ると、book の値を出さず探索の値だけにします。

## book の整理

「book」→「book の整理・書き出し」：

| 項目 | エンジンのコマンド |
|---|---|
| 保存する・別の名前で保存する | `book save` |
| 新しい空の book | `book new` |
| book の深さを変える | `book depth` |
| 局面を問題の形式でログに表示 | `book problem` |
| 別の book を取り込む | `book merge` |
| 今の局面から先だけを残す | `book subtree` |
| 片方が最善を打つ変化だけを残す | `book prune` |
| deviate3 X Y でたどれない局面を消して軽くする | `book reduce`（下） |
| テキストファイルに書き出す・読み込む | `book export`・`book import` |
| 最善の手順を棋譜に書き出す | `book extract` |

subtree・prune・reduce・import・new などの book を変えるコマンドの後は、エンジンを閉じるときに book のファイルが上書きされることがあります。確かめの窓にも出ます。先にコピーを取ってください。

## book を軽くする（book reduce）

「book」→「book の整理・書き出し」→「deviate3 X Y でたどれない局面を消して軽くする（book reduce）…」。指定の局面から `book deviate3 X Y` でたどれる局面だけを残し、ほかを消して book を小さくします（v4.5.5-nikque.20・newedax.5 からのエンジンの機能）。

1. 窓で、1 手の石損の上限 X（0〜129）、石損の合計の上限 Y（0〜254）、どこから（初期局面から・今の局面から）を選びます。X・Y の初めの値は「調べる範囲」の値です。ふつうは初期局面からにします。今の局面からにすると、初期局面からここまでの局面も消えます。
2. GUI は先にエンジンに数えさせ（`book reducecount`。book は変えません）、残る局面と消える局面の数を窓で見せます。
3. 「OK」を押すと、学習と同じ形で `book reduce X Y` を行います。終わると、ログに残した局面と消した局面の数が出ます。

- 残るのは、その局面と、そこから「1 手の石損が X 以下、石損の合計が Y 以下」の手でたどれる局面です（`book deviate3 X Y` が、広げる局面を探すときに歩く範囲と同じ）。残った局面の評価値は、先に計算し直した後の値から変わりません。
- 数えている間や、数え終わって窓が出る前に「入出力」→「裏の処理を止める」を選んだとき、エンジンが閉じたとき（book やエンジンを替えたときを含む）は、book を軽くしません。窓を出している間にエンジンが閉じたときも、「OK」を押しても行いません（0.2.1 から）。
- 指定の局面から先の book が壊れているとき（すでに石のあるマスへの手や、同じ局面に戻る手のつながりがあるとき）は、その旨を知らせて何もしません（v4.5.5-nikque.21・newedax.6 からのエンジン）。
- 消した book は、エンジンを閉じると book のファイルに保存されます。元の book を残したいときは、先にファイルのコピーを取るか、「別の名前で保存する…」で保存してから「book を読み込み直す」で元に戻してください。
- このコマンドを知らない古いエンジン（nikque.19・newedax.4 まで）では、その旨を知らせて何もしません。
- スクリプトでは `book reduce X Y`（今の局面からは `book reduce X Y here`）。確かめの窓を出さずに行います（[10. スクリプト](10-scripts.md)）。
